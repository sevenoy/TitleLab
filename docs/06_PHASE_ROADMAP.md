# TitleLab Phase Roadmap

当前阶段：TITLELAB-MINIPROGRAM-PHASE-0-PRD-AND-DATABASE-DESIGN

## Phase 0：PRD 与数据库设计

唯一目标：完成需求、数据库、架构、部署方向和验收文档。

允许做：

- 读取少量现有 Web 页面理解功能。
- 新增或更新 `docs/` 文档。
- 明确 Phase 1 输入。

禁止做：

- 写业务代码。
- 创建后端、小程序、数据库 migration。
- 部署、push、连接服务器或数据库。

验收标准：

- PRD 覆盖项目定位、目标用户、核心场景和功能规划。
- 数据库设计覆盖用户、workspace、内容、分类、标签、收藏、历史、生成记录、快照、审计。
- 路线图覆盖 Phase 0 到 Phase 4。
- 文档明确下一步最小建议。

停止条件：

- 9 个 Phase 0 文档写入完成。
- 文档级检查通过。
- 无业务代码修改。

## Phase 1：后端骨架 + 数据库基础 migration

唯一目标：建立可运行后端骨架、基础数据库结构和健康检查。

允许做：

- 创建后端项目骨架。
- 创建基础 migration。
- 实现 `/healthz` 和 `/api/meta`。
- 添加本地开发说明和 `.env.example`。

禁止做：

- 实现完整业务 CRUD。
- 连接生产数据库。
- 部署生产。
- 把真实密钥写入仓库。

验收标准：

- 本地后端可启动。
- 健康检查可返回。
- migration 可在本地空库执行。
- 无真实 secret 入库或入仓。

停止条件：

- 后端骨架、基础表和健康接口完成。
- 只进入 Phase 2 前先更新 handoff。

## Phase 2：认证 / RBAC / 用户隔离 / 基础内容 API

唯一目标：建立可权限隔离的用户和内容 API。

允许做：

- 微信登录或测试登录。
- 用户、workspace、成员角色。
- 标题/文案列表、详情、基础新增编辑。
- 分类与标签读取。

禁止做：

- 直接做小程序完整 UI。
- 上线生产。
- 做危险清空和快照恢复。

验收标准：

- 不同用户只能访问授权 workspace。
- API 返回格式稳定。
- 基础内容 API 有权限测试。

停止条件：

- Auth、RBAC、基础内容读取闭环完成。

## Phase 2.5：测试 HTTPS API / 小程序合法域名预检查

唯一目标：确认测试 API 与小程序合法域名上线条件。

允许做：

- 测试环境 HTTPS 检查。
- 域名备案状态确认。
- 微信公众平台合法域名配置清单。
- API smoke 测试。

禁止做：

- 改生产 DNS。
- 未经确认部署生产。
- 跳过备案与证书检查。

验收标准：

- 测试 API 可通过 HTTPS 访问。
- 小程序 request 合法域名候选明确。
- 不暴露敏感响应。

停止条件：

- 输出合法域名预检查报告。

## Phase 3：小程序只读 MVP

唯一目标：小程序端完成只读使用闭环。

允许做：

- 登录。
- 标题/文案列表。
- 搜索和筛选。
- 详情、复制、收藏/星标。
- 最近使用。

禁止做：

- 批量导入。
- 管理员危险操作。
- AI Key 前端配置。
- 复杂编辑。

验收标准：

- 小程序可登录并读取授权数据。
- 搜索、筛选、详情、复制、收藏可用。
- 用户隔离通过。

停止条件：

- 只读 MVP 可在开发者工具完成演示。

## Phase 4：CRUD / 导入 / 管理后台

唯一目标：补齐编辑、导入、后台管理和数据运维。

允许做：

- 内容 CRUD。
- 批量导入。
- 审核状态。
- 管理后台。
- 快照、导出、去重、归一化。
- AI 标题仿写后端代理。

禁止做：

- 未审计的危险清空。
- 前端保存密钥。
- 无权限校验的导出或恢复。

验收标准：

- 编辑和导入有审计日志。
- 快照恢复有确认和权限控制。
- AI 生成记录可追踪。

停止条件：

- 管理后台核心流程通过验收，进入正式部署准备。
