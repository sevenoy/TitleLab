# TitleLab Mini Program Architecture

当前阶段：Phase 0 - 小程序架构规划，不创建小程序代码。

## 1. 架构目标

小程序端承担高频、轻量、移动优先的内容使用体验。它不直接连接数据库，不保存敏感密钥，不承担管理员危险操作。所有业务数据通过后端 API 获取。

## 2. 页面规划

Phase 3 只读 MVP 建议页面：

- 登录页：微信授权登录，展示隐私与使用说明入口。
- 首页：标题库、文案库、星标、最近使用入口。
- 标题列表页：搜索、主分类筛选、账号分类筛选、标签筛选、星标入口。
- 标题详情页：正文、分类、标签、复制、收藏/取消收藏。
- 文案列表页：搜索、分类筛选、星标入口。
- 文案详情页：正文、分类、标签、复制、收藏/取消收藏。
- 我的页：当前用户、workspace、最近使用、设置、退出。

Phase 4 后再考虑：

- 内容新增/编辑。
- 批量导入。
- AI 标题仿写。
- 管理员轻量审核。

## 3. 数据流

- 小程序启动后调用 `GET /api/meta` 获取版本和环境公开信息。
- 登录页调用微信登录能力获取 code，再调用后端 `POST /api/auth/wechat-login`。
- 后端返回 session token、小程序可见用户资料、workspace 列表和当前权限。
- 列表页通过 `GET /api/contents` 查询标题/文案。
- 详情页通过 `GET /api/contents/:id` 获取单条内容。
- 收藏通过 `POST /api/favorites` 和 `DELETE /api/favorites/:id`。
- 复制成功后调用 `POST /api/usage-events` 记录 `copy`。

## 4. 缓存策略

- 小程序端可缓存最近列表、分类、标签和用户设置。
- 缓存只用于体验优化，不作为权限判断来源。
- 服务端返回内容需包含 `updated_at`，用于后续增量同步。
- 离线模式 Phase 3 不承诺完整编辑能力，只提示网络状态。

## 5. 权限与安全

- 小程序端不出现数据库连接串、AppSecret、AI API Key、服务器密码或腾讯云密钥。
- 所有接口必须带会话凭证，由后端校验 workspace 权限。
- 列表接口不能返回用户无权访问的数据。
- 管理能力默认不放入 Phase 3 小程序端。

## 6. 与现有 Web 功能的关系

迁移保留：

- 标题/文案 Tab 概念 -> 小程序两个入口。
- 搜索、分类、账号分类、场景标签 -> 小程序筛选条件。
- 星标置顶 -> 小程序星标列表和列表优先排序。
- 复制使用 -> 小程序详情页核心按钮。
- 主题/显示偏好 -> 后续用户设置。

迁移调整：

- PWA 离线安装 -> 小程序原生入口，不再依赖 Service Worker。
- 前端登录白名单 -> 后端微信登录与角色体系。
- 云端快照 -> 管理后台能力，不作为小程序主流程。
- 危险清空 -> 仅后台可用，需二次确认和审计。
- AI Key 本地填写 -> 后端托管配置，小程序只发生成请求。

## 7. Phase 3 验收重点

- 小程序能登录并展示当前用户。
- 小程序能列出标题和文案。
- 搜索、分类、账号分类筛选可用。
- 详情页复制可用并记录历史。
- 收藏/星标可用且按用户隔离。
- 无敏感配置出现在小程序代码或日志。
