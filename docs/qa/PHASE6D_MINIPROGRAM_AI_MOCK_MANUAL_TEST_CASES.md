# Phase 6D Mini Program AI Mock Manual Test Cases

当前阶段：Phase 6D DevTools/manual acceptance。所有用例只验证本地 mock 页面，不真实请求后端、不调用 OpenAI、不上传体验版、不提交审核。

## 测试前置

- 微信开发者工具导入目录：`miniprogram/`。
- `compileType=miniprogram`。
- `urlCheck=true`。
- 默认 gate：`realApiGateEnabled=false`、`authRealApiGateEnabled=false`、`aiRealApiGateEnabled=false`。
- 不登录也应可验收 AI mock 页面。

## 用例 1：打开首页

- 步骤：导入项目后打开首页。
- 预期：显示“标题与文案素材”，列表、搜索和筛选区域可见。
- 备注：不应弹出登录要求，不应请求真实后端。

## 用例 2：从首页进入 AI 标题生成

- 步骤：点击首页“AI 标题生成”。
- 预期：进入 AI 页面，顶部显示 Mock-only 和本地 mock 提示。
- 备注：页面路径应为 `pages/ai/index`。

## 用例 3：空输入生成

- 步骤：保持输入框为空，点击生成或触发重试。
- 预期：出现空输入错误提示，显示可理解的错误文案。
- 备注：不得请求后端。

## 用例 4：短输入生成

- 步骤：输入少于 6 个字，例如“旅拍”，观察生成按钮或点击生成。
- 预期：页面提示还差多少字，生成不可用或进入输入不足错误态。

## 用例 5：正常输入生成

- 步骤：输入一段正常素材，点击生成。
- 预期：出现 loading 态后展示结果列表；结果包含标题、rationale、tags、riskLevel、score。

## 用例 6：示例输入填充

- 步骤：点击“香港迪士尼旅拍”“摄影师跟拍”或“求婚记录”示例。
- 预期：输入框填充示例内容，字符计数更新，生成按钮可用。

## 用例 7：tone/platform/contentType/count 组合

- 步骤：分别调整内容、语气、平台、数量，执行生成。
- 预期：结果数量匹配 count 上限，结果文案随组合变化；仍显示 mock-only 和 0 成本含义。

## 用例 8：复制单条

- 步骤：生成结果后点击任意“复制标题”。
- 预期：出现“标题已复制”成功 toast。

## 用例 9：复制全部

- 步骤：生成多条结果后点击“复制全部”。
- 预期：出现“已复制全部标题”成功 toast；剪贴板内容包含编号后的全部标题。

## 用例 10：清空

- 步骤：生成结果后点击“清空”。
- 预期：输入、字符计数、结果、warning、错误、复制状态和上次生成时间均复位。

## 用例 11：重试

- 步骤：生成结果后点击“重新生成”；或在可重试错误态点击“重试”。
- 预期：重新生成沿用上一轮输入和选项；页面不跳转、不请求真实后端。

## 用例 12：过长输入

- 步骤：粘贴超过 1200 字的文本。
- 预期：输入被页面上限截断或提示已到上限，字符计数显示 1200 附近，不上传内容。

## 用例 13：疑似敏感输入 warning

- 步骤：输入包含疑似 token、secret、cookie 或长随机串的素材。
- 预期：结果不原样扩散该片段，warning 显示疑似敏感片段已处理。
- 备注：不要输入真实 secret，只使用假样例。

## 用例 14：mock-only 提示

- 步骤：观察 AI 页面顶部和 loading 文案。
- 预期：页面明确提示本地 mock、不上传内容、不请求后端。

## 用例 15：返回首页

- 步骤：从 AI 页面返回首页。
- 预期：首页列表、搜索和筛选仍可用。

## 用例 16：不登录状态

- 步骤：清除本地登录态或不执行登录，直接进入 AI 页面。
- 预期：mock 页面可用，不弹出真实登录要求，不调用 `wx.login`。

## 用例 17：网络关闭状态下仍 mock 可用

- 步骤：在开发者工具或系统网络条件允许时关闭网络，再执行示例输入和生成。
- 预期：AI mock 页面仍可生成本地标题；若 DevTools 环境无法完全断网，则记录环境限制。

## 完成标准

- 所有非环境限制用例通过。
- 若有失败，使用 bug report template 记录。
- 不上传体验版、不提交审核、不打开真实 gate。
